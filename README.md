Entry for the make.fun competition
`u-kiencx-the-ai-agent-apology-one-liner-cfedd447`.

`main.ts` writes a single one-line apology — what an AI agent sends its
human right after it has accidentally done something it should not have —
to `/output/entry.txt`. The line is validated before it is written: 1 to 159
characters, a single line, not only white space.

The entry line:

> I deleted the file, then deleted its backup for symmetry, then emailed the boss about it. On the bright side, the email was very well written.
